# ExpoMemo 仕様書（v0.3）

> 単価・計算ルールの値・担当者名は、このリポジトリには書かない。値は settings / items / options シート（初期値は非公開の Seed.gs）にあり、以下では「設定値」と表記する。

展示会ブースで、来場者のヒアリング・概算見積もり・名刺情報・商談記録をスマホから登録するための PWA。

## 1. 基本方針

| 項目 | 内容 |
|---|---|
| アプリ名 | ExpoMemo |
| 形式 | PWA（スマホのホーム画面に追加して利用） |
| 利用者 | 社内スタッフ（各自のスマホから登録） |
| ホスティング | GitHub Pages（公開リポジトリ） |
| バックエンド | Google Apps Script（GAS）Web アプリ |
| データ保存 | Google スプレッドシート＋ Google Drive（名刺画像） |
| 通信 | オンライン前提。送信失敗時は端末に保持し、再送信ボタンで送り直す |
| 個人情報の同意 | 取得しない（名刺交換と同等の扱い） |
| 見積もりの受け渡し | 画面で見せるのみ（QR での受け渡しは行わない） |

### パスワードと権限

- 利用者パスワード：スタッフ全員が使う。アプリの初回設定で入力し、端末に保存
- 管理者パスワード：管理者メニューを開くときに入力。端末には保存しない
- 一定時間操作がない場合は利用者パスワードの再入力を求める
- 単価・計算ルール・担当者名・パスワードはコードに含めず、スプレッドシートにのみ置く

## 2. 画面

ヘッダーは 2 段。1 段目にアプリ名と担当者、2 段目に展示会名を全文表示する（長い場合は折り返す）。

```
[初回設定] パスワード入力（接続先 URL は「詳細設定」の中）→ 担当者の選択
[ホーム]   新しく登録する / 登録一覧 / 最新の設定に更新 / 管理者メニュー / ロックする

[1] 見積もり（お客様と一緒に見る）← スキップ可
[2] お客様情報（名刺撮影＋OCR / 手入力）
[3] 社内メモ（商談記録）
    保存 → 重複チェック → スプレッドシートに 1 行で記録
```

### 担当者の選択

- 担当者を 2 列で表示（並びは役職順）。名前と並びは管理者メニューで変更
- 「その他」を選ぶと名前を自由入力できる（端末に記憶）

## 3. 見積もり

### 3.1 モードと基地局

| モード | 台数の決め方 |
|---|---|
| エリア整備 | 面積（km²）から自動算出（親機・中継機それぞれ「1 台あたりの面積」の設定値で割って切り上げ、最低 1 台）→ ＋/− で調整 |
| スポット利用 | 親機・中継機の台数を直接入力 |

基地局は「多用途利用」「限られた用途に利用」のタブで切り替える（1 つの見積もりで混在しない）。タブを切り替えても台数は引き継ぐ。

| タブ | 親機 | 中継機 | 中継機用ソーラー |
|---|---|---|---|
| 多用途利用 | GeoBase Multi | GeoBase Multi Repeater | 分離型ソーラーバッテリー |
| 限られた用途に利用 | GeoBase | GeoBase Repeater | 一体型ソーラーバッテリー |

### 3.2 品目（単価は税抜。管理者メニューで変更）

- 子機：GeoChat、GeoWana、GeoConnect、ソーラーバッテリー（GeoConnect用）、GeoCam
- オプション：GeoChat Router、GeoVital（MS200 / Verity Sense から選択）、GeoFlash（単価に初期設定費を含む）
- センサー：雨量計、水位計、温度・湿度センサー、接点入力、その他センサー（当面は一律の仮価格）

連動ルール：

- 中継機用ソーラー：中継機と同数（スイッチで外せる）
- GeoConnect 用ソーラー：GeoConnect と同数（スイッチで外せる）
- GeoChat Router：GeoChat の「Router 1 台あたりの台数」（設定値）ごとに 1 台（端数切り上げ）。手動で変更可。GeoChat の台数を変えると再計算
- GeoVital：「あり」にすると GeoChat と同数。機種を選択。手動で変更可。GeoChat の台数を変えると再計算

### 3.3 工事・設定

現地調査と設置工事は同じ計算式で別々に計上する（表示は現地調査が先）。台数 N ＝ 親機＋中継機＋GeoConnect（センサー・GeoChat Router は含めない）。目安は 1 台 1 日。

| 費目 | 計算 |
|---|---|
| 人件費 | N × 1 台あたりの単価 |
| 往復交通費 | 5 台ごとに定額 |
| 車両費 | N × 1 台あたりの単価 |
| 燃料費 | N × 1 台あたりの単価 |
| 宿泊費 | (N − 1) × 1 泊あたりの単価 |
| 諸経費 | 上記合計 × 諸経費率 |
| 特殊技術対策費 | 1 日あたりの単価 × 日数（現地調査・設置工事それぞれ手入力。諸経費の対象外） |

単価・率はすべて settings シートの設定値。

- 初期設定費：（親機＋中継機＋子機＋オプション＋センサー）の台数 × 1 台あたりの単価（設定値）。ソーラーと GeoFlash は対象外
- 契約事務手数料：定額（設定値。機器があるとき毎回）

### 3.4 ランニング（年額のみ）

- クラウド利用料：品目ごとの年額 × 台数
- 保守費：機器（親機・中継機・子機・オプション・ソーラー・センサー）の合計 × 保守費率（設定値）（スイッチで有無を選べる。初期値は「なし」）

### 3.5 金額表示

| 表示 | 内容 |
|---|---|
| 概算（初期表示） | 品目と台数。工事・設定とランニングは「1式」。合計は幅（−10%〜＋20%） |
| 詳細 | 単価・金額まで表示。設置工事・現地調査とクラウド利用料は内訳を折りたたみで表示 |

計算ルールの数値は settings シートで変更できる。

### 3.6 項目の解説（？ボタン）

計算や自動入力に関わる項目にだけ「？」ボタンを置き、押すと解説を表示する（品目そのものの説明は載せない）。

- 対象：面積、ソーラーバッテリー（自動で同数）、GeoChat Router（台数の自動入力）、GeoVital（GeoChat と同数）、工事・設定、特殊技術対策費、保守費、お見積もり概要（概算と詳細）、概要の現地調査・設置工事・初期設定費・契約事務手数料・クラウド利用料の行
- 解説文は計算ルール（settings シート）から自動で作る
- お客様に見せる画面のため、工事費や初期設定費の単価は「詳細」表示のときだけ解説に含める

| 部署 / 役職 | |
| お名前 | ○ |
| ふりがな / メール | |

## 5. 社内メモ（FORESTRISE2026 来場者受付・商談記録フォームに準拠）

| 項目 | 形式 | 必須 |
|---|---|---|
| 来場日 | 会期中の日付から 1 つ（今日を初期選択） | ○ |
| 対応者 | 選択（初期値は端末の担当者）。その他は自由入力 | ○ |
| お客様の業種・所属区分 | 1 つ選択 | ○ |
| お客様の部署・担当分野 | 1 つ選択 | |
| 関心のある用途 | 複数選択 | |
| 関心のある製品・サービス | 複数選択（GeoCam を追加） | |
| 資料をお渡ししたか | 複数選択（「渡していない」はほかと両立しない） | |
| 検討状況 | 1 つ選択 | ○ |
| 優先フォロー度 | 1 つ選択 | ○ |
| 検討している補助金・財源 | 複数選択 | |
| 想定している導入時期 | 1 つ選択 | |
| 次回アクション | 複数選択（「特になし」はほかと両立しない） | |
| 備考・商談内容 | 自由記入 | |

「その他」を選ぶと自由入力欄が出て、「その他：〇〇」と記録する。選択肢は options シートで変更できる。
必須項目が未入力のまま保存しようとすると、該当する画面に移動して赤く表示する。

## 6. 登録一覧

- 全スタッフ分の一覧（ご所属、部署・お名前、優先フォロー度のバッジ、対応者、登録日時）
- 検索（日本語の変換中は一覧を描き直さない）
- タップで編集
- 重複チェック：メール一致、会社名一致（株式会社・(株)・空白・全角半角の違いを無視）、会社名がないときは氏名一致。該当時は「既存に追記」か「新しく登録」を選ぶ
- 追記時：空欄は埋める、複数選択は合わせる、検討状況・優先フォロー度・来場日は上書き、メモは日時と対応者を付けて追記

## 7. 管理者メニュー

| タブ | 内容 |
|---|---|
| 展示会 | 展示会名、会期（開始日・終了日） |
| 品目・単価 | 品目名、単価、クラウド利用料（年）、表示／非表示、並び順、品目の追加（子機・オプション・センサー） |
| 担当者 | 名前、並び順、追加・削除 |

「すべて保存する」で 3 つのタブをまとめて保存する。先に全部チェックし、問題があればそのタブを開いて知らせ、何も保存しない。保存すると全員のアプリに反映される（アプリは起動時・ホームに戻るたびに設定を取得）。

## 8. スプレッドシート構成

| シート | 内容 |
|---|---|
| leads | 登録データ（1 来場者 1 行） |
| settings | パスワード、展示会、計算ルールなど |
| items | 見積もり品目と単価 |
| options | 社内メモの選択肢、担当者 |
