# ExpoMemo

展示会ブースで、来場者のヒアリング・GEO-WAVE の概算見積もり・名刺の登録・商談記録をスマホから行う PWA。
仕様は [docs/SPEC.md](docs/SPEC.md) を参照。

- 画面：GitHub Pages（このリポジトリ）
- データ：Google スプレッドシート＋Google Drive（Google Apps Script 経由）
- 名刺 OCR：Google Drive の OCR（無料）＋自動振り分け

## まずはお試し（GAS なし）

`js/config.js` が `GAS_URL = 'mock'` のままだと「お試しモード」で動く。

- 利用者パスワード：`demo`
- 管理者パスワード：`admin`

データはその端末のブラウザにだけ保存され、名刺 OCR はサンプルの名刺データを返す。単価・担当者名は架空の値。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

## 本番のセットアップ

### 1. スプレッドシートと GAS

1. Google ドライブで新しいスプレッドシートを作る（名前は例：`ExpoMemo データ`）
2. 「拡張機能 > Apps Script」を開く
3. `gas/Code.gs` の中身を、エディタの `コード.gs` に丸ごと貼り付ける
4. 本番の単価・計算ルール・担当者を入れるため、別途受け取った `Seed.gs` を追加する（エディタの「ファイルを追加 > スクリプト」で `Seed` を作り、中身を貼り付ける）。`Seed.gs` は **GitHub に置かない**（`.gitignore` 済み）
5. 左の「プロジェクトの設定（歯車）」で「appsscript.json マニフェスト ファイルをエディタで表示する」をオンにし、`appsscript.json` を `gas/appsscript.json` の中身で置き換える
6. エディタ上部の関数選択で `setup` を選んで「実行」
   - 初回は権限の確認が出るので許可する（スプレッドシート・ドライブ・ドキュメントへのアクセス）
   - 実行ログに **利用者パスワード** と **管理者パスワード** が表示される（settings シートの `token` と `adminToken`）
   - 好きなパスワードにしたい場合は、settings シートの値を書き換える（総当たり対策のため 12 文字以上）
   - `Seed.gs` がないと、架空のダミー値でセットアップされる（実行ログに表示される）
7. 「デプロイ > 新しいデプロイ」で種類「ウェブアプリ」を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
8. 表示された URL（`https://script.google.com/macros/s/.../exec`）を控える

GAS のコードを変更したときは「デプロイを管理 > 編集 > バージョン：新バージョン」で更新する（URL は変わらない）。

### 2. アプリの設定

1. `js/config.js` の `GAS_URL` を、控えた URL に書き換える
2. `sw.js` の `VERSION` を 1 つ上げる（利用者の端末に新しい版を届けるため）
3. コミットして push

### 3. GitHub Pages で公開

1. GitHub のリポジトリで「Settings > Pages」を開く
2. Source を「Deploy from a branch」、Branch を公開したいブランチ・`/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/wpc_expomemo/` で開けるようになる

### 4. 運用開始前に

1. アプリのホームの「管理者メニュー」を管理者パスワードで開き、展示会名と会期を設定する
2. 品目・単価を確認する（センサーの仮価格や試験機価格など、確定したら更新）
3. スタッフのスマホで URL を開き、利用者パスワードで接続して担当者を選び、「ホーム画面に追加」

## どこで何を変えるか

| 内容 | 変更する場所 |
|---|---|
| 展示会名・会期 | アプリの管理者メニュー「展示会」 |
| 品目名・単価・クラウド利用料・表示／非表示・並び順・品目の追加 | アプリの管理者メニュー「品目・単価」 |
| 担当者の名前・並び順 | アプリの管理者メニュー「担当者」 |
| 計算ルール（面積の目安、工事費の単価、諸経費・保守費の率、概算の幅など） | スプレッドシートの `settings` シート |
| 社内メモの選択肢（業種・用途・製品・資料・検討状況など） | スプレッドシートの `options` シート |
| パスワード | スプレッドシートの `settings` シート（`token` / `adminToken`） |

管理者メニューの「すべて保存する」は、展示会・品目・担当者の 3 つをまとめて保存する。アプリは開くたび・ホームに戻るたびに最新の設定を取得する。すぐ反映させたいときはホームの「最新の設定に更新」。

`leads` シートは 1 行目が日本語の見出し、2 行目がシステム用のキー。2 行目は消さないこと。

## 機密情報について

リポジトリは公開でも問題ない作りにしている。

- 単価・計算ルール・担当者名・パスワードはコードに含めず、スプレッドシートにだけ置く
- コード内の初期値（`js/defaults.js`、`gas/Code.gs`、`js/estimate.js` の `DEFAULT_RULES`、テスト）はすべて架空の値。本番の初期値は非公開の `Seed.gs` で入れる
- アプリは利用者パスワードを付けて GAS から設定を取得する。パスワードがなければ GAS は何も返さない
- 管理者メニューでの変更は、GAS 側でも管理者パスワードを確認する

## ブランドの差し替え

- 色：`css/brand.css` の色を変更
- ロゴ：`icons/logo-mark.png`（ロゴマーク）と `icons/logo-horizontal.png`（横長ロゴ）を差し替え
- アプリアイコン：`icons/icon-192.png`・`icon-512.png`・`icon-maskable-512.png`・`apple-touch-icon.png` を差し替え
- 差し替えたら `sw.js` の `VERSION` を上げる

## 開発

```bash
npm test   # 見積もり計算・名刺の振り分け・GAS の処理のテスト（Node.js 20 以上）
```

ビルドは不要。ファイルを編集してそのまま公開できる。
初期データ（品目・ダミー単価・選択肢）は `js/defaults.js` と `gas/Code.gs` の両方にあり、テストで一致を確認している。
